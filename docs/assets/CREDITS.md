# Image credits

The before and after pictures in the README were made from public-domain images. Each was
set as the wallpaper of a test GNOME Shell, captured with `vividctl` off and on (value 400), and the
two captures were joined in the middle (`scripts/split-screenshot.py`, see
`extensions/gnome/test/screenshots.sh`).
